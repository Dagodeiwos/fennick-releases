# Fennick add-ons for WoW Forever — releases

Fennick is a free, modular add-on suite for WoW Forever: **Fennick's Beast Core** (shared settings, look and commands) plus optional modules — **Guidepost** (leveling guide), **Rest** (inn and rested-XP helper), **Reputation** (turn-ins you can do now), **Merchant's Favor** (vendor helper) and **Fox Trials** (tester checklist).

This repository holds only release zips, the changelog and bug reports. Source code is not published here.

## Download and install
1. Open [Releases](https://github.com/Dagodeiwos/fennick-releases/releases) and download the **Install-All** zip (Core + Guidepost + Rest + Reputation + Merchant's Favor), or Core plus the modules you want.
2. Unzip into your game's `Interface/AddOns/` folder (each `Fennick_*` folder sits directly in `AddOns`).
3. Restart the game and type `/fennick help`.

Every module needs Fennick's Beast Core. Fox Trials is for playtesters only.
