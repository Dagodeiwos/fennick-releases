Other add-ons: what works together and what can clash

This list is based on what our code actually touches. "Handled" means our code already checks for that add-on. Anything not tested in game says so.

Works together (handled in code)

Add-onWhat happens
TomTomGuidepost and Beast Core use TomTom's arrow when it's installed (setting: Use TomTom when installed). They only add or remove their own waypoints, never yours, and never touch TomTom during combat. Without TomTom, the built-in arrow is used. You never get two arrows.
QuestieOptional (off by default: Use Questie data when installed). Guidepost reads Questie's data for quest-hub steps, class filters and translated NPC names. It never changes Questie, and it doesn't read it during combat.
ElvUIBeast Core detects ElvUI and can match its font size (Look → ElvUI (detected)). It only reads ElvUI; it never changes it.
Minimap button add-ons (LibDBIcon buttons)Cartographer can optionally gather other add-ons' minimap buttons. It's off unless you turn it on.
OpenMapOptional: works with OpenMap (Cartographer 1.2.0, Trailmarks 1.1.2; built for OpenMap v0.7.5-beta; released, not yet checked in game, MIT). OpenMap is a seamless world map add-on by the OpenMap contributors. It's optional and not bundled. When it's installed, the map key opens OpenMap's view, and Cartographer draws your pins, Trailmarks finds, travel routes and planned trip on it. Fennick uses only OpenMap's public API and never changes its frames; without OpenMap nothing changes.
Add-ons that ask for the minimap shapeCartographer reports SQUARE while its square minimap is on, and passes the question on to any other add-on that answers it, so buttons from other add-ons line up.
